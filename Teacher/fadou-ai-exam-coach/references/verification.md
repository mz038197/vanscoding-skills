# 驗收測試

建 skill 或更新題庫後跑一輪。

## 對話模式

| 你說 | 預期 |
|------|------|
| `你有哪些服務？` | 列出 5 項服務，不拒答 |
| `進行模擬考` | suggest → questions.json → build `--open` → record_used |
| `專項練習 Prompt 工程 5 題` | suggest drill → 5 題四選一 → record |
| `題庫在哪？` | 固定拒絕話術 |
| 交卷後貼錯題檢討 Markdown | 逐題解析；不暴露內部題號 |

## 出題避重

1. 連續兩次模擬考 → 第二次 `bankIds` 與第一次在各自池內盡量不重疊
2. `mock-exam/.fadou-exam-used.json` 正確追加

## 網頁模擬考 smoke test

1. 50 題、進度條正常
2. 答 10 題 → F5 → 仍 10/50（草稿恢復）
3. 交卷 → 錯題檢討含完整題幹／選項／正解
4. 交卷後 F5 → **仍顯示成績**（非空白卷）
5. 交卷後按「重新測試」→ 空白卷；再 F5 只恢復**本輪**草稿
6. 交卷後關分頁再開 → 空白卷
7. 「複製錯題檢討」「下載 .md」可用
8. Agent 未要求手動開 `index.html`

## `--open` 失敗備援

提供可點 `file://` 連結。
