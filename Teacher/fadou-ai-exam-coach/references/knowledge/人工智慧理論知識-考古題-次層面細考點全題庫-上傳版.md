## 資料科學基礎

### 資料編碼與特徵

#### 重點概念

**核心概念**
- **Label Encoding（標籤編碼）**：類別 → 整數（如 A=4, B=3）；可能引入**錯誤大小關係**。
- **One-Hot Encoding（一位有效編碼）**：每類別一欄 0/1，**無序**類別常用。
- **Dummy Encoding（虛擬編碼）**：類似 One-Hot 但少一欄以避免**完全共線**。
- **連續 vs 離散特徵**：數值可無限細分 vs 類別／計數；編碼方式依型態選。

**辨識要點**
- 無序類別（車輛類型、學院）→ **One-Hot / Dummy**（不是 Label）。
- 配對表格題 → 甲=Label、乙=One-Hot、丙=Dummy（ITS 附錄 A 常考）。
- 連續特徵（血壓、車速）→ **不需** One-Hot。

**常見混淆**
- 所有類別欄位都用 Label Encoding。
- One-Hot 與 Dummy 完全相同（Dummy 少基準類別欄）。

**備考速記**
- 類別無序 → **One-Hot**；表格配對 → **Label / One-Hot / Dummy**。

### 資料品質與前處理

#### 重點概念

**核心概念**
- **GIGO**：資料品質決定模型上限；缺失、不平衡、偏差都會拖累表現。
- **缺失值**：空白欄位需補值、刪列或另建指標——不能無視。
- **樣本偏差（sample bias）**：訓練樣本不能代表母體（如重低音偏好過多）。
- **特徵選擇**：與目標**無關**的特徵應移除，避免雜訊。

**辨識要點**
- 表格缺值 + 類別不平衡 → **以上皆是**（資料缺失＋不平衡）。
- 與目標無關特徵（配色主題 vs 訂閱）→ **不合用特徵**。
- COVID 後旅遊資料分布改變 → **訓練資料過時／分布漂移**。

**常見混淆**
- 資料越多越好、不需檢查品質。
- 所有欄位都當有效特徵。

**備考速記**
- 缺值／不平衡／偏差 → **前處理**；無關特徵 → **移除**。

### 資料科學／Kaggle

#### 重點概念

**核心概念**
- **資料集選擇**：數量足夠、元素完整、**貼近任務場景**比來源名氣更重要。
- **開放式資料／資料協作**：政府、機構共享資料解決公共問題。
- **Kaggle**：競賽式資料科學平台；強調實作與資料驅動問題解決。

**辨識要點**
- 選資料集 → **數量足夠** + **缺少或毀損元素**（兩項都重要）。
- 公共問題共享資料 → **開放式資料**或**資料協作**。

**常見混淆**
- 學術來源一定優於商業來源（應看任務適配）。
- 檔案格式本身決定能否建模（通常次要）。

**備考速記**
- 資料集 → **量＋質＋場景**；公共共享 → **開放／協作**。

## 深度學習

### 訓練資料與模型訓練

#### 重點概念

**核心概念**
- **GIGO**（Garbage in, garbage out）：訓練資料品質決定生成品質；高品質、多樣化資料是準確性與泛化能力的基礎。
- **訓練流程**：收集大量資料集 → 模型架構設計 → **訓練**（調參）→ 評估與改進；「哪一步需要收集大量資料」→ **訓練**階段。
- **損失函數（Loss Function）**：衡量模型預測與真實值的**誤差**，用於優化參數——不是「生成新樣本」或「被損耗的資料」。
- **過擬合（Overfitting）**：訓練集表現好、測試集差 → 需正則化、Dropout、資料增強等**抗過適**手段（不是減少訓練資料或一味降學習率）。
- **風格／領域控制**：創作特定風格（如歌詞）常靠**特定風格訓練資料**，而非只調 Temperature。
- **生成式 AI 資料痛點**：相對判別式 AI，GenAI 更缺**具邏輯性與準確性的標記數據**。

**辨識要點**
- GIGO 最相關 → **訓練資料品質**（不是訓練時間、參數多寡）。
- 提高泛化 → **多樣化資料集**（不是只用高品質或減少資料量）。
- 確保準確可靠 → **高品質訓練資料**（不是固定或單一來源）。
- 監督學習 → **完全標記資料**（不是部分或無標記）。
- 過擬合對策 → **正則化／抗過適技術**（不是減少訓練資料）。

**常見混淆**
- 損失函數 = 生成新數據或評估「被損耗的資料」。
- 只調 **Temperature** 就能完全決定創作風格（風格常來自訓練資料）。
- 泛化 = 只用高品質、少樣化資料即可。
- 過擬合時**減少訓練資料**是正解。

**備考速記**
- 資料三寶 → **品質、多樣、充分標記**。
- Loss → **預測 vs 真實的誤差**；過擬合 → **正則化**。
- 收集大量資料 → **訓練**步驟；GIGO → **訓練資料品質**。

**考古題印證（本細考點歸納）：**

- 多題正解：**評估每條路徑並選擇最優路徑**
- 多題正解：**幫助模型透過多步推理解決問題**
- 多題正解：**只作為生成模型的輸入的一部分**
- 多題正解：**混淆矩陣（推導）**

### 生成式模型／GAN

#### 重點概念

**核心概念**
- **GAN**（Generative Adversarial Network）= **生成式對抗網路**；2014 年 Goodfellow 提出。
- **雙網路結構**：**Generator（生成器）** 造假樣本；**Discriminator（判別器）** 辨真假；兩者對抗訓練。
- **用途**：提升生成內容**真實性與可信度**；常見於**圖片生成、影片生成、圖片合成**（自動生成逼真圖片）。
- **訓練方式**：固定一方、訓練另一方，輪流更新（常從隨機雜訊生成開始）。

**辨識要點**
- 問 GAN 全名／縮寫 → **Generative Adversarial Network**（不是 Artistic Network、Graphical Analysis Node）。
- 問提升生成真實性 → **GAN**（不是 CNN、決策樹、隨機森林）。
- 問圖片生成常用技術 → **GAN**（不是 RL、NLP）。
- 問 GAN 主要應用 → **圖片生成**（不是資料庫管理、預測分析）。
- 影片生成核心 → **GAN**。

**常見混淆**
- **CNN** = 生成圖片的主要技術（CNN 多為判別／特徵提取）。
- **強化學習、NLP** 當圖片生成首選。
- GAN = 增強解析度或自動標註（那是其他 CV 任務）。

**備考速記**
- GAN = **生成 vs 判別、對抗、逼真圖／影**。
- 圖像生成題 → 先選 **GAN**；縮寫 G = **Generative**。

### LLM／Transformer

#### 重點概念

**核心概念**
- **LLM**（Large Language Model）= 大語言模型；參數量大，擅長**文字理解與生成**。
- **Transformer**：現代 LLM（如 GPT、ChatGPT）的骨幹架構；**ChatGPT 基於 Transformer 訓練**。
- **代表模型**：Google **BERT**（2018）、OpenAI **GPT** 系列；GPT 主要用於**文字生成**。
- **文字生成技術基礎**：依 **NLP（自然語言處理）** 理解與生成文本（題庫常將 NLP 列為文字生成依據）。
- **ChatGPT 限制**：可生成流暢文字，但**不能真正感受或表達情感**（「何者為非」常考）。
- **不同 LLM** 影響 → 提升生成內容的**多樣性與品質**（不只是加資料或減算力）。

**辨識要點**
- ChatGPT「何者為非」→ **能真正感受情感**。
- GPT 主要領域 → **文字生成**（不是聲音合成、圖片生成）。
- 文字生成依據 → **NLP**（相對機器學習、決策樹等干擾）。
- LLM 與 GenAI → **多樣性與品質**（模型差異的效應）。

**常見混淆**
- ChatGPT **有情感、意識**（錯）。
- GPT = 影像或語音生成主力。
- BERT／GPT 與 Transformer 無關。

**備考速記**
- LLM → **Transformer、文字、BERT/GPT**。
- ChatGPT 非 → **情感**；GPT 領域 → **文字生成**。

- **CNN**（Convolutional Neural Network）= **卷積神經網路**；擅長影像**特徵提取、分類、辨識**。
- **判別式 vs 生成式**：CNN 屬**判別式模型**（分類／辨識）；**VAE、CycleGAN、GAN** 屬生成式（創造新影像）。
- **歷史**：LeCun 等發展的 CNN 被視為現代卷積網路重要里程碑；**AlexNet** 為深度學習在影像領域的經典代表。
- **任務區分**：影像**分類／特徵識別** → CNN；**生成新圖** → GAN 等生成模型。

**辨識要點**
- AIGC 影像中「判別式、非生成用」→ **CNN**（不是 VAE、CycleGAN）。
- 問深度學習框架／工具 → **TensorFlow、PyTorch**（不是 Excel、Word）。
- 圖片生成 → **GAN**；圖片分類／特徵 → **CNN**。
- AlexNet 相關 → 影像深度學習、CNN 脈絡。

**常見混淆**
- CNN 用來**生成**逼真新圖（那是 GAN）。
- VAE／CycleGAN 當「判別式分類模型」。
- 把辦公軟體當深度學習框架。

**備考速記**
- **分類／特徵 = CNN**；**生成新圖 = GAN**。
- 判別式 vs 生成式 → 先問題幹要「辨識」還是「創造」。

### Prompt／推理技巧

#### 重點概念

**核心概念**
- **CoT**（Chain-of-Thought，思維鏈）：引導模型**多步推理**解決複雜問題（不是只適用簡單題）。
- **ToT**（Tree of Thoughts，思維樹）：建構多條推理路徑，**評估並選最優路徑**（不是加更多訓練資料或增強記憶）。
- **ReAct**：結合推理（Reasoning）與行動（Acting），可與外部工具互動。
- **Temperature**：控制輸出**隨機性／創意度**；高溫較多元，低溫較確定（風格控制常仍靠訓練資料）。
- **Few-shot**：在 prompt 中提供少量範例，引導模型格式與風格。
- **進階 prompt 原則**：清楚、具體、可執行；**過度專業術語堆砌**常是錯誤選項。

**辨識要點**
- CoT 特點 → **多步推理**（不是僅簡單題、無法複雜題）。
- ToT → **評估路徑、選最優**（不是加資料、增記憶）。
- 歌詞風格題：矩陣中 3-1 與 3-10 **正解不一致**（Temperature vs 訓練資料），備課請對照矩陣逐題核。
- 「寫出好的 prompt」→ 具體、分步、角色清楚（不是術語越多越好）。

**常見混淆**
- CoT 只能解簡單題。
- ToT = 增加訓練資料或模型記憶容量。
- Temperature  alone 可完全取代風格訓練資料（實務與題庫其他題可能衝突）。

**備考速記**
- CoT → **多步**；ToT → **多路徑＋評選**。
- Prompt 好 = **清楚具體**，不是術語堆疊。

### DNN／神經網路

#### 重點概念

**核心概念**
- **DNN**（Deep Neural Network）= **深度神經網路**；多隱藏層，能學習複雜特徵。
- **深度學習（DL）**：以 DNN 為核心的機器學習分支；生成式 AI 的**主要技術基礎**之一。
- **與 GenAI 關係**：文字、影像、語音等生成式模型多建立在**深層神經網路**上（非傳統淺層 ML  alone）。
- **組成**：輸入層、隱藏層、輸出層；透過**反向傳播**與 loss 優化權重。

**辨識要點**
- GenAI 主要技術 → **深度學習／DNN**（不是僅決策樹、SVM）。
- 問「神經網路層數」vs 應用效果 → 層數不是唯一決定因素（如聲音複製看樣本品質）。
- 與 CNN、RNN 關係：CNN／RNN 是 DNN 的**特定架構**變體。

**常見混淆**
- 生成式 AI 只靠傳統 ML、不需深度網路。
- 層數越多效果必然越好（忽略資料與任務）。

**備考速記**
- GenAI 骨幹 → **DL / DNN**；
- 具體架構 → 文字常 RNN/Transformer，影像常 CNN。

### RNN／LSTM／序列

#### 重點概念

**核心概念**
- **RNN**（Recurrent Neural Network）= **循環／遞迴神經網路**；處理**序列資料**（文字、時間序列）。
- **LSTM**（Long Short-Term Memory）：RNN 變體，透過門控機制緩解**長期依賴**問題。
- **比較**：一般 RNN 對**長序列**記憶較弱；LSTM 更擅長**長期依賴**與長文本脈絡。
- **與 Transformer 關係**：早期 NLP 常用 RNN/LSTM；現代 LLM 多改用 Transformer，但考題仍考 RNN/LSTM 基礎。

**辨識要點**
- 問 RNN 全名 → **Recurrent Neural Network**（不是 Random、Recursive 等拼錯選項）。
- 長期依賴／長序列 → **LSTM**（優於基本 RNN）。
- 序列、時間相關文字任務 → RNN 家族。

**常見混淆**
- RNN 與 CNN 用途互換（CNN 偏空間、RNN 偏序列）。
- 基本 RNN 已完美處理任意長依賴（需 LSTM/GRU 或 Transformer）。

**備考速記**
- 序列 → **RNN**；長記憶 → **LSTM**；R = **Recurrent**。

### 綜合理論

#### 重點概念

**核心概念**
- **生成式 AI 目的**：**創造或生成新的資料／內容**——不是辨識、分類既有資料（那是判別式 AI）。
- **輸出可靠性**：使用 GenAI 後須**查證輸出**（幻覺、錯誤可能）；不能完全信任未經審核的結果。
- **資料前處理**：高品質生成依賴**收集與清理高品質資料**（前處理是關鍵步驟之一）。
- **跨模態因素**：聲音複製效果受**原始聲音樣本品質**影響大（勝過單純增加層數或頻寬）。

**辨識要點**
- GenAI 主要目的 → **生成新資料**（不是分類照片、辨識物體）。
- 聲音複製 → **樣本品質**（不是層數、頻寬）。
- 確保可用輸出 → **人工查證／驗證**（不是盲目信任）。
- 前處理重點 → **資料蒐集與品質**（不是只調模型）。

**常見混淆**
- GenAI = 分類／辨識系統。
- 聲音克隆只要**加深網路**就好、忽略錄音品質。
- AI 輸出**無需查證**即可正式使用。

**備考速記**
- GenAI = **創造新內容**；用前 → **查證**；聲音 → **樣本品質**。

## 機器學習

### 機器學習概念

#### 重點概念

**核心概念**
- **ML（Machine Learning）**：從資料學習模式，**優化模型參數**——在 GenAI 中常負責訓練與調參，**不是直接生成新樣本**。
- **與 GenAI 分工**：ML 優化 GenAI 參數；生成由生成式模型（GAN、LLM 等）完成；ML 也可**評估**模型但「直接用 ML 生成新樣本」常為錯。
- **損失函數**：評估預測誤差，驅動 ML 訓練（見「訓練資料與模型訓練」）。
- **應用辨識**：生長預測、法務文件輔助、TAIDE 等 → 常考 **機器學習**（不是 VR、區塊鏈）。
- **法律 AI 現狀**：實際貢獻是**提升效率**（審閱、檢索、草擬）——不是 AI 法官、完全消除法律程序。

**辨識要點**
- ML 在 GenAI 中 → **優化參數**（不是直接生成樣本或 sole 性能評估工具）。
- TAIDE 計畫技術基礎 → **機器學習**。
- 農業生長模型 → **機器學習**（不是 NLP、資料檢索）。
- 法律領域 → **效率工具**（不是取代法官、保證絕對公正）。

**常見混淆**
- ML = 直接產生新數據。
- AI 已可**完全取代**法官且判決必然公正。
- 生長預測用 NLP 或區塊鏈。

**備考速記**
- ML → **學參數、不直接生成**；應用題 → 先想 **ML**。

### 監督／非監督／強化

#### 重點概念

**核心概念**
- **監督學習（Supervised Learning）**：使用**完全標記**的輸入–輸出資料訓練（GenAI 微調常屬此類）。
- **非監督學習**：無標記或僅部分結構，從資料中發現模式（如聚類）。
- **強化學習（RL）**：**代理（Agent）** 在**環境**中採取**動作**，依回饋（獎懲）學習策略——不是「動作」或「環境」本身當 RL 定義主體。
- **半監督**：介於兩者，部分標記。

**辨識要點**
- 監督學習 → **完全標記資料**（不是部分或無標記）。
- RL 定義核心角色 → **代理（Agent）**（題 3-33）。
- RL 三要素常考：Agent、Environment、Action、Reward（代理是學習主體）。

**常見混淆**
- 監督學習 = 無標記或部分標記即可。
- RL = **環境**或**動作**當作 RL 本身的定義名稱。

**備考速記**
- 監督 → **全標記**；RL → **Agent 在環境中學策略**。

### 模型評估與指標

#### 重點概念

**核心概念**
- **過擬合（overfitting）**：訓練好、測試差；**低度擬合**：訓練測試都差。
- **損失函數（loss）**：衡量預測誤差，用於優化——不是「被損耗的資料」。
- **混淆矩陣**：依假陽性／假陰性成本選模型（如寧可誤陽不可漏陽）。
- **抗過擬合**：限制樹深度、限制神經元、正則化、更多樣資料等。

**辨識要點**
- 訓練準確高、測試準確低 → **過度擬合**。
- 決策樹限深度、NN 限神經元 → **皆可**抗過擬合。
- 低度擬合時**加正則化**通常無效 → 應增模型容量或改善特徵。

**常見混淆**
- 訓練 loss 低 = 一定泛化好。
- 過擬合時一味**減少訓練資料**是正解。

**備考速記**
- 過擬合 → **正則／限深度**；Loss → **預測誤差**。

### AI倫理與部署

#### 重點概念

**核心概念**
- **部署倫理**：模型上線後發現對特定族群表現差 → **補資料重訓**、**暫停下線**，而非限制使用者或刻意降準。
- **團隊組成**：AI 專案需領域專家、資料科學、NLP 等——行政長官未必適合核心開發。
- **競爭與安全**：竊取訓練資料、未授權使用資料皆屬高風險行為。

**辨識要點**
- 語音助理對女性辨識差 → **增女性資料重訓** + **暫時離線**（合乎道德）。
- 維持部署效能 → **現場回饋修正標籤**、**健康監視**、持續迭代。

**常見混淆**
- 只讓「辨識成功」者使用 = 排除弱勢族群（不合乎道德）。
- 換程式語言就能解決公平性問題。

**備考速記**
- 公平性問題 → **補資料＋重訓**；部署 → **監控＋迭代**。
