**核心概念**

- Python → **高階、直譯、免費、可移植**；非編譯。

## 基礎語法

### 變數與型態

#### 重點概念

**核心概念**
- **註解**用 **`#`**（不是 `//` 或 `$`）。
- **保留字**不可當變數名（如 `if`、`print`）；`mary`、`_x`、`str56` 合法。
- **型態**：`56.0` → **float**；`8 + True` → **9**（True 當 1）。
- **字串 + 數字**不可直接相加：`23 + "67"` 錯；需 `int()` 或 `str()` 轉型。
- **字串相加**為連接：`"78" + "12"` → **`7812`**；數值相加 `78+12` → **90**。
- **AI 生成程式碼可讀性** → **具體變數名稱**（GenAI 題）。

**辨識要點**
- 錯誤變數名 → 含 **`if`** 或 **`print`** 等保留字。
- `type(56.0)` → **float**（不是 int／double；Python 無 double 關鍵字）。
- 哪行會錯 → **`print(23 + "67")`**。

**常見混淆**
- Python 用 `//` 當單行註解（那是 C/Java）。
- 字串與數字自動相加（會 TypeError）。
- 「減少註解、縮短變數名」可提升 AI 程式碼品質（錯）。

**備考速記**
- 註解 **`#`**；保留字禁作變數名；`True` 可當 **1**。
- 可讀性 → **具體變數名** + 適度註解。

### 運算子

#### 重點概念

**核心概念**
- **`%` 模除**：`96 % 5` → **1**（餘數）。
- **複合指定**：`num **= 3` 且 `num=5` → **125**（5³）。
- **優先順序最高**（題庫選項）常考 **`-(負)`** 一元運算（高於 `*`、`and`、`+=`）。
- 邏輯：`and` 兩側皆 True 才 True；`or` 任一侧 True 即 True。

**辨識要點**
- `%` → 取餘數，不是除法商。
- `**=` 為累次乘方指定。
- 優先順序題 → 先選**一元負號**。

**常見混淆**
- `/` 與 `%` 用途互換。
- `and` / `or` 優先序與算術運算子搞混。

**備考速記**
- `%` = 餘數；`**` = 次方；一元 `-` 優先度高。

## 流程控制

### 條件判斷

#### 重點概念

**核心概念**
- Python 區塊：**冒號 `:` + 縮排**。
- `if` 條件 **True** 才執行區塊；`if…elif…else` 全 False 走 **`else`**。
- 條件可為**關係**或**邏輯**運算式（皆可）。
- **縮排錯誤**會改變執行結果（題庫常給未縮排 `print` 的陷阱）。
- 巢狀 if：注意 `else` 配對哪一層 `if`。

**辨識要點**
- 區塊符號 → **`:`**（不是 `!`、`#`、反斜線）。
- `a=3` 且 `if(a==5): print(1)` 無縮排 print → 可能只印 **`2`**（依題目結構）。
- `a>5 or b>5` 與 `and` 對照 → 理解短路與真假值。

**常見混淆**
- False 時仍執行 if 區塊。
- 以為 elif 在全部 False 時執行（應為 else）。

**備考速記**
- if → **True 才進**；全 False → **else**；區塊靠 **`:` + 縮排**。

## 迴圈與 range

### 迴圈與range

#### 重點概念

**核心概念**
- **`range(5)`** → `[0,1,2,3,4]`；`range(6,0,-2)` → `[6,4,2]`。
- **`for n in range(1,5,2)`** 結束後 **n** 為最後一值 → **3**。
- **`while`** 初條件 False → **一次都不執行**。
- **`break`** 離開迴圈；**`continue`** 跳過本次、回迴圈開頭。
- 巢狀迴圈累加／印 `#` 題：手 trace 內外層次數。

**辨識要點**
- 提前離開 → **break**（不是 return／exit／pause）。
- 跳過本輪 → **continue**。
- `while(i<=n)` 累乘 1~5 → **120**（5!）。

**常見混淆**
- `range(5)` 從 1 開始（錯；從 0）。
- `break` 與 `continue` 對調。

**備考速記**
- range → **左含右不含**；break 離開；continue 下一輪。

## 串列與元組

### 串列操作

#### 重點概念

**核心概念**
- **list 索引**由 **0** 起；`list1[0]` 為**第一個元素值**（不是 0）。
- **負索引**：`number[-4]`、`number[9]==number[-1]` 等題需手算。
- **`sorted(list, reverse=True)`** 回傳新排序串列，不改原串列（題庫常考）。
- **`for item in list`** 不需索引即可遍歷。

**辨識要點**
- `print(list1[0])` 對 `[1,2,3,4,5]` → **1**。
- 排序後 list2 → **降序新 list**（原 list 不變）。
- 索引越界 → **list index out of range**。

**常見混淆**
- 以為 `[0]` 回傳索引 0 而非元素。
- `sorted()` 會 in-place 改原串列（錯；回傳新 list）。

**備考速記**
- 索引 **0 起**；**sorted** 回新 list；**for in** 遍歷。

## 字典

### 字典操作

#### 重點概念

**核心概念**
- **dict** 以鍵值對儲存；**無固定順序**（隨機／插入序，非「依序排列」）。
- **`d[key]`** 鍵不存在 → **Error**；**`d.get(key, default)`** 可給預設。
- **`d["新鍵"]=值`** → 新增；**`clear()`** 刪全部元素。
- **`in`** 測鍵是否存在；**`keys`/`values`/`items`** 取鍵、值、鍵值對。
- **`setdefault(k)`** 鍵不存在時插入並回傳 **None**（題庫 2-73）。

**辨識要點**
- 關於 dict「錯誤敘述」→ **資料依序排列**。
- `print(d[0])` → **Error**（鍵應為可哈希鍵名，非整數索引）。
- `d.get("巴樂", 60)` 無鍵 → **60**。

**常見混淆**
- dict 像 list 用數字索引 `d[0]`。
- `keys()` 取「鍵值對」（那是 **items**）。

**備考速記**
- dict → **鍵值、無序**；`get` 安全；`items` = 鍵+值。

## 函式與模組

### 內建函式與模組

#### 重點概念

**核心概念**
- 函式可 **0／1／多個返回值**（題：以上皆可）。
- 常用內建：**`max()`、`pow()`、字串 `replace`/`startswith`/`find`**。
- **`random.randint(1,10)`** 含端點 1～10 → **0 不可能**。
- **`random.randrange(0,15,3)`** → 0,3,6,9,12（**不含 15**）。
- **`time.sleep`** 暫停；**`tm_min` 範圍 0～59**。

**辨識要點**
- `pow(2,5,7)` → 2⁵ mod 7 = **4**。
- `"hospital".replace("s","t")` → **hotpital**。
- `find("p")` → 索引 **3**。

**常見混淆**
- `randrange` 上界包含（錯；同 range 不含 stop）。
- `replace` 只換第一個（實際全替換除非 count 限制）。

**備考速記**
- randint **含端點**；randrange **不含 stop**；sleep 在 **time** 模組。

## 檔案與例外處理

### 檔案與例外

#### 重點概念

**核心概念**
- **`open(filename[, mode[, encode]])`**：**filename 必填**；**mode 預設讀取 `r`**。
- 開檔函式 → **`open()`**（不是 file／input／output）。
- **`read()`** 可讀指定長度；**`readlines()`** 回傳串列、含 **`\n`**。
- **`w` 模式** 寫入後檔案物件**僅寫**（已 write 後不可讀）。
- **try / except / finally**：**finally 無論是否例外都執行**；`print(x)` x 未定 → except 印 **y**，finally 印 **z** → **yz**。
- 繁中 Windows 預設編碼常考 **cp950**。

**辨識要點**
- mode 預設 → **讀取 r**。
- 必填參數 → **filename**。
- finally 一定執行 → 選 **finally**。
- n=1 且 try 成功 → 印 **1**（無例外不走 except）。

**常見混淆**
- `w` 模式可讀可寫同一物件隨意讀（題目常考已 write 的狀態）。
- except 沒例外也會跑（錯）。

**備考速記**
- open → **filename 必填、預設 r**；finally **必跑**；Win 中文 **cp950**。

## GenAI 與 Python 應用

### GenAI程式碼

#### 重點概念

**核心概念**
- **AI 生成程式碼**常見應用：自動化開發、翻譯、生成設計等——**不是**「建造房屋」這類實體工程。
- 生成流程：理解需求 → 蒐集資料 → 訓練 → 生成初稿 → **人工修正**（訓練**之後**的關鍵步驟）。
- 品質考量：**模型準確度、輸入資料品質、風格可讀性**重要——**硬體資源**通常不是「生成程式碼時」的首要考量（題 2-3）。
- 可讀性：**具體變數名**、適度拆分函式、保留必要註解與空白。

**辨識要點**
- 「不是常見應用」→ **建造房屋**。
- 「不是重要考量」→ **使用的硬體資源**。
- 訓練之後 → **人工修正程式碼**。
- 提高可讀性 → **具體變數名稱**。

**常見混淆**
- 以為 AI 生成程式可直接上線無需人工審查。
- 為可讀性「減少函式拆分」（錯）。

**備考速記**
- 非應用 → **蓋房子**；非考量 → **硬體**；訓練後 → **人工改碼**。

### GenAI與Python

#### 重點概念

**核心概念**
- **GPT** 為生成高品質文字的**語言模型**——不是程式語言（題 2-8「何者為 LM」）。
- 文字連貫性技術可考 **長短期記憶模型（LSTM 等）** 概念（題 2-5）。
- Python 在 GenAI 生態中常作**串接 API、資料處理、訓練腳本**語言，但 **GPT 本身不是 Python 套件名**。

**辨識要點**
- 高品質文字 LM → **GPT**（不是 Python／Sora／Notion AI）。
- 上下文連貫 → **長短期記憶模型**（不是字典查詢／反向搜索）。
- ChatGPT 類產品基於 **Transformer／LLM**，與 Python 語言層級不同。

**常見混淆**
- 選項把 **Python** 當「語言模型」。
- LSTM 與「字典查詢」改善連貫性（錯）。

**備考速記**
- LM → **GPT**；連貫 → **LSTM／記憶模型**；Python = **語言，非 LM**。
